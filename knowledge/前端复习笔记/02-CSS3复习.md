# CSS3 复习

> CSS（Cascading Style Sheets，层叠样式表）负责网页的视觉表现，CSS3 在原 CSS2.1 基础上新增了选择器、圆角、渐变、过渡、动画、变形、Flex/Grid 布局等大量现代特性。

## 一、CSS 基础

### 1.1 引入方式（内联、内部、外部样式表）

| 方式 | 写法 | 特点 |
| --- | --- | --- |
| 内联样式 | `<div style="color:red">` | 写在标签 `style` 属性中，权重高，但结构与样式耦合，不推荐 |
| 内部样式表 | `<style> ... </style>` 写在 `<head>` 中 | 结构与样式半分离，适合单个页面 |
| 外部样式表 | `<link rel="stylesheet" href="style.css">` | 完全分离，可被多页面复用，可被浏览器缓存，**推荐** |

```html
<!-- 外部样式表 -->
<link rel="stylesheet" href="./css/style.css">

<!-- 内部样式表 -->
<style>
  body { margin: 0; }
</style>

<!-- 内联样式 -->
<div style="color: red;">内联</div>
```

### 1.2 注释

```css
/* 这是 CSS 注释，只能使用这一种 */
/* 注释不能嵌套 */
```

> ⚠️ CSS 注释不支持 `//`，且不能嵌套。

## 二、选择器（重点）

### 2.1 基础选择器（标签、类、id、通配符）

| 选择器 | 写法 | 说明 | 权重 |
| --- | --- | --- | --- |
| 标签选择器 | `div {}` | 选中所有该标签 | 0,0,1 |
| 类选择器 | `.box {}` | 选中 class 为 box 的元素 | 0,1,0 |
| id 选择器 | `#box {}` | 选中 id 为 box 的元素（页面唯一） | 1,0,0 |
| 通配符选择器 | `* {}` | 选中所有元素 | 0,0,0 |

```css
p { color: #333; }       /* 标签 */
.box { width: 100px; }   /* 类 */
#header { height: 60px; }/* id */
* { margin: 0; padding: 0; } /* 通配符 */
```

### 2.2 复合选择器（后代、子代、兄弟、相邻兄弟）

| 选择器 | 写法 | 说明 |
| --- | --- | --- |
| 后代选择器 | `.father .son` | 选中 `.father` 内**所有层级**的 `.son` |
| 子代选择器 | `.father > .son` | 仅选中 `.father` 的**直接子元素** `.son` |
| 相邻兄弟 | `.a + .b` | 紧跟在 `.a` **后面**的**一个**同级 `.b` |
| 通用兄弟 | `.a ~ .b` | `.a` **后面所有**同级 `.b` |

```css
.nav a { color: #fff; }        /* 后代：.nav 下所有 a */
.nav > li { list-style: none; }/* 子代：.nav 的直接 li */
h2 + p { margin-top: 0; }      /* 相邻兄弟：h2 后紧邻的一个 p */
h2 ~ p { color: gray; }        /* 通用兄弟：h2 后所有同级 p */
```

### 2.3 伪类选择器

#### 链接伪类（顺序：LVHA）

```css
a:link    { color: #333; } /* 未访问 */
a:visited { color: #999; } /* 已访问 */
a:hover   { color: red; }  /* 鼠标悬停 */
a:active  { color: orange; }/* 鼠标按下未松开 */
```

> ⚠️ 链接伪类必须按 **L → V → H → A** 顺序书写，否则会因权重相同而被覆盖失效。

#### 用户行为伪类

| 伪类 | 说明 |
| --- | --- |
| `:hover` | 鼠标悬停 |
| `:active` | 鼠标按下未松开 |
| `:focus` | 元素获得焦点（input） |

#### 结构伪类（重点）

| 伪类 | 说明 |
| --- | --- |
| `:first-child` | 父元素第一个子元素 |
| `:last-child` | 父元素最后一个子元素 |
| `:nth-child(n)` | 第 n 个子元素 |
| `:nth-last-child(n)` | 倒数第 n 个子元素 |
| `:first-of-type` | 同类型第一个 |
| `:last-of-type` | 同类型最后一个 |
| `:nth-of-type(n)` | 同类型第 n 个 |
| `:only-child` | 父元素唯一子元素 |

`nth-child` 表达式：

| 写法 | 含义 |
| --- | --- |
| `:nth-child(3)` | 第 3 个 |
| `:nth-child(odd)` / `:nth-child(2n+1)` | 所有奇数行 |
| `:nth-child(even)` / `:nth-child(2n)` | 所有偶数行 |
| `:nth-child(3n)` | 第 3、6、9… 个 |
| `:nth-child(-n+3)` | 前 3 个 |

```css
/* 表格隔行变色 */
tr:nth-child(odd)  { background: #f5f5f5; }
tr:nth-child(even) { background: #fff; }
```

> ⚠️ `:nth-child` 先匹配位置再匹配类型，`:nth-of-type` 先按类型分组再匹配位置，类型不一致时差异明显。

#### 表单伪类

| 伪类 | 说明 |
| --- | --- |
| `:checked` | 选中的表单元素（radio/checkbox） |
| `:disabled` | 被禁用 |
| `:enabled` | 可用 |
| `:focus` | 获得焦点 |
| `:placeholder-shown` | 显示 placeholder 时 |

```css
input:checked + label { color: red; }
input:disabled { background: #eee; }
```

### 2.4 伪元素选择器（::before / ::after）

- 伪元素通过 CSS 创建"虚拟元素"，必须设置 `content` 属性才会显示
- 默认是行内元素，常用于装饰图标、清除浮动、文字前缀

```css
.box::before {
  content: "★";          /* 必需，可为空字符串 */
  color: gold;
  margin-right: 6px;
}
.box::after {
  content: "";
  display: block;
  clear: both;           /* 双伪元素清除浮动常用 */
}
```

> ⚠️ `::before` / `::after` 是 CSS3 推荐写法，单冒号 `:before` 是旧语法（CSS2），仍兼容但建议双冒号。

### 2.5 属性选择器

| 写法 | 说明 |
| --- | --- |
| `[attr]` | 含有该属性 |
| `[attr=val]` | 属性值**完全等于** val |
| `[attr^=val]` | 属性值以 val **开头** |
| `[attr$=val]` | 属性值以 val **结尾** |
| `[attr*=val]` | 属性值**包含** val |

```css
[disabled] { opacity: .5; }
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; }   /* https 开头 */
a[href$=".pdf"] { color: red; }      /* .pdf 结尾 */
a[href*="baidu"] { color: blue; }    /* 包含 baidu */
```

### 2.6 CSS 权重优先级

**优先级（从高到低）：**

```
!important  >  行内 style  >  id  >  类/伪类/属性  >  标签/伪元素  >  通配符
```

**权值（特异性）计算：**

| 等级 | 选择器 | 权值 |
| --- | --- | --- |
| (a, b, c) | a: id 数量；b: 类/伪类/属性 数量；c: 标签/伪元素 数量 | 比较 a → b → c |
| `!important` | 提升到最高 | 优先于普通声明 |
| 继承的样式 | 无权重 | 最低，可被任何显式声明覆盖 |

```css
#nav .item li {}        /* (1,1,1) */
.box a {}               /* (0,1,1) */
* {}                    /* (0,0,0) */
```

> ⚠️ 权重**不可进位**：10 个类选择器 (0,10,0) 仍小于 1 个 id 选择器 (1,0,0)。
> ⚠️ `!important` 滥用会破坏层叠规则，应尽量避免。

## 三、字体与文本样式

### 3.1 字体属性

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `font-size` | 字号 | `12px` / `14px` / `1.2rem` |
| `font-family` | 字体族 | `"Microsoft YaHei", Arial, sans-serif` |
| `font-weight` | 字重 | `normal`(400) / `bold`(700) / `100~900` |
| `font-style` | 字体样式 | `normal` / `italic`（斜体）/ `oblique` |
| `line-height` | 行高 | `1.5`（推荐无单位倍数）/ `24px` |

**`font` 简写（顺序固定）：**

```css
/* font: style weight size/line-height family; */
font: italic 700 16px/1.5 "Microsoft YaHei", sans-serif;
```

> ⚠️ `font` 简写中 `size` 和 `family` 不可省略，且 `size` 必须在前、`line-height` 紧跟 `size` 用 `/` 分隔。

### 3.2 文本属性

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `color` | 文字颜色 | `red` / `#fff` / `rgb()` / `rgba()` |
| `text-align` | 水平对齐 | `left` / `center` / `right` / `justify` |
| `text-decoration` | 文本修饰 | `none` / `underline` / `line-through` / `overline` |
| `text-indent` | 首行缩进 | `2em`（推荐 em 单位） |
| `line-height` | 行高 | `1.5` / `24px` |
| `letter-spacing` | 字间距 | `2px` |
| `word-spacing` | 单词间距 | `4px` |
| `white-space` | 空白处理 | `nowrap`（不换行）/ `pre` / `pre-wrap` |
| `text-overflow` | 溢出处理 | `ellipsis`（省略号）/ `clip` |

**单行文本省略号（重点）：**

```css
.ellipsis {
  white-space: nowrap;       /* 1. 不换行 */
  overflow: hidden;          /* 2. 溢出隐藏 */
  text-overflow: ellipsis;   /* 3. 省略号 */
}
```

**多行文本省略号：**

```css
.ellipsis-multi {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;   /* 显示 2 行 */
  overflow: hidden;
}
```

### 3.3 继承性

**会继承的属性（与文字相关）：** `color`、`font-*`、`text-*`、`line-height`、`letter-spacing`、`visibility`、`cursor`、`list-style` 等。

**不会继承的属性（与盒子相关）：** `width`、`height`、`margin`、`padding`、`border`、`background`、`position`、`float` 等。

> ⚠️ `a` 标签的颜色、`h1~h6` 的字号不会自动继承父级，需显式设置（如 `a { color: inherit; }`）。

## 四、盒模型（重点）

### 4.1 标准盒模型与怪异盒模型

| 模式 | `box-sizing` | `width` 包含范围 |
| --- | --- | --- |
| 标准盒模型（默认） | `content-box` | 仅 content |
| 怪异盒模型 | `border-box` | content + padding + border |

```css
/* 推荐：全局开启怪异盒模型，便于尺寸计算 */
* { box-sizing: border-box; }
```

```css
/* 标准盒模型：实际占用宽度 = 100 + 10*2 + 1*2 = 122px */
.box-content {
  box-sizing: content-box;
  width: 100px; padding: 10px; border: 1px solid #000;
}
/* 怪异盒模型：实际占用宽度 = 100px（content 自适应） */
.box-border {
  box-sizing: border-box;
  width: 100px; padding: 10px; border: 1px solid #000;
}
```

> ⚠️ 实际开发中通常全局设置 `box-sizing: border-box`，避免 padding/border 撑大盒子。

### 4.2 边框 border（含圆角 border-radius）

```css
.box {
  border: 1px solid #ccc;          /* 简写：width style color */
  border-radius: 10px;             /* 四角圆角 */
  border-radius: 50%;              /* 圆形（正方形）/椭圆 */
  border-radius: 10px 20px 30px 40px; /* 左上 顺时针 */
}
```

| `border-style` | 说明 |
| --- | --- |
| `none` | 无边框 |
| `solid` | 实线 |
| `dashed` | 虚线 |
| `dotted` | 点线 |
| `double` | 双线 |

```css
/* 表格合并相邻边框 */
table { border-collapse: collapse; }
```

### 4.3 内边距 padding

```css
.box { padding: 10px; }              /* 上下左右 */
.box { padding: 10px 20px; }         /* 上下 10 左右 20 */
.box { padding: 10px 20px 30px; }    /* 上 左右 下 */
.box { padding: 10px 20px 30px 40px; }/* 上 右 下 左（顺时针） */
```

> ⚠️ padding 不会撑破父盒子的情况：子元素没有指定 width（或 width 为 auto），此时 padding 会向内挤压 content。

### 4.4 外边距 margin

#### 块级元素水平居中

```css
/* 必须满足：盒子有明确 width */
.box {
  width: 200px;
  margin: 0 auto;   /* 上下 0，左右 auto */
}
```

#### 外边距合并（兄弟元素）

垂直方向上相邻的两个 margin 会取**较大值**，而非相加。

```css
.box1 { margin-bottom: 20px; }
.box2 { margin-top: 30px; }
/* 实际间距：30px，不是 50px */
```

#### 外边距塌陷（父子元素）

父元素没有上边框/上 padding/触发 BFC 时，子元素的 `margin-top` 会"穿透"传递给父元素。

**解决方案（任选其一）：**
1. 给父元素设置 `border-top: 1px solid transparent;`
2. 给父元素设置 `padding-top: 1px;`
3. 给父元素设置 `overflow: hidden;`（触发 BFC，推荐）
4. 给父元素设置 `display: flow-root;`（现代方案，无副作用）

> ⚠️ 行内元素设置 `margin-top/margin-bottom` 不生效；浮动、绝对定位元素不会发生外边距塌陷。

### 4.5 盒子阴影 box-shadow

```css
box-shadow: h-shadow v-shadow blur spread color inset;
```

| 参数 | 说明 |
| --- | --- |
| `h-shadow` | 水平偏移（必填），正右负左 |
| `v-shadow` | 垂直偏移（必填），正下负上 |
| `blur` | 模糊距离，值越大越模糊 |
| `spread` | 阴影扩展，正扩大负缩小 |
| `color` | 阴影颜色 |
| `inset` | 内阴影（可选，默认外阴影） |

```css
.box { box-shadow: 0 4px 12px rgba(0,0,0,.15); }
.card:hover { box-shadow: 0 8px 20px rgba(0,0,0,.2); }
```

> ⚠️ box-shadow 不占空间，不影响布局。

### 4.6 背景 background

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `background-color` | 背景色 | `#fff` / `rgba()` |
| `background-image` | 背景图 | `url("a.jpg")` |
| `background-repeat` | 平铺 | `repeat` / `no-repeat` / `repeat-x` / `repeat-y` |
| `background-position` | 位置 | `center` / `10px 20px` / `right top` |
| `background-size` | 大小 | `cover` / `contain` / `100px 50px` |
| `background-attachment` | 滚动方式 | `scroll` / `fixed`（视差滚动） |
| `background` | 简写 | `color image repeat position/size` |

```css
/* 背景图居中、不平铺、铺满 */
.banner {
  background: url("bg.jpg") no-repeat center/cover;
}
/* 视差滚动效果 */
body {
  background: url("bg.jpg") no-repeat center top fixed;
  background-size: cover;
}
```

| `background-size` | 说明 |
| --- | --- |
| `cover` | 等比缩放铺满容器，可能裁切 |
| `contain` | 等比缩放至完整显示，可能留白 |

#### 渐变

```css
/* 线性渐变：linear-gradient(方向, 颜色1 位置, 颜色2 位置) */
.box {
  background: linear-gradient(to right, #ff0000, #0000ff);
  background: linear-gradient(45deg, #ff0000 0%, #0000ff 100%);
}
/* 径向渐变 */
.box {
  background: radial-gradient(circle at center, #fff, #000);
}
```

> ⚠️ 渐变属于 `background-image`，不可与 `background-color` 同时简写在 `background` 中时需注意顺序。

## 五、显示模式与布局

### 5.1 元素显示模式

| 模式 | 特点 | 代表标签 |
| --- | --- | --- |
| 块级 `block` | 独占一行；可设宽高；默认宽度为父容器宽 | `div` `p` `h1~h6` `ul` `li` `form` |
| 行内 `inline` | 一行多个；不可设宽高（宽高由内容决定）；上下 margin/padding 不生效 | `a` `span` `em` `strong` |
| 行内块 `inline-block` | 一行多个；可设宽高 | `img` `input` `button` `td` |

```css
/* 显示模式转换 */
a { display: block; }       /* 行内 → 块级 */
div { display: inline; }    /* 块级 → 行内 */
span { display: inline-block; } /* → 行内块 */
li { display: none; }       /* 隐藏，不占位 */
```

| `display` 值 | 说明 |
| --- | --- |
| `none` | 隐藏，**不占位**，不响应事件 |
| `block` | 块级 |
| `inline` | 行内 |
| `inline-block` | 行内块 |
| `flex` | 弹性容器 |
| `grid` | 网格容器 |

> ⚠️ `display:none` 与 `visibility:hidden` 区别：前者不占位，后者保留位置。

### 5.2 浮动布局

```css
.box { float: left; }   /* 左浮动 */
.box { float: right; }  /* 右浮动 */
.box { float: none; }   /* 默认 */
```

**浮动特性：**
1. 脱离标准文档流，不再保留原来位置
2. 一行多个显示，顶部对齐
3. 具有行内块特性（可设宽高）
4. 只影响后面的标准流元素

> ⚠️ 浮动的盒子不会有外边距合并问题；浮动元素不会撑开父容器，会导致父元素高度塌陷。

#### 清除浮动的方法

| 方式 | 写法 | 优缺点 |
| --- | --- | --- |
| 额外标签法 | 在末尾加 `<div style="clear:both"></div>` | 简单，但添加无语义标签 |
| 单伪元素 | `.clearfix::after { content:""; display:block; clear:both; }` | 推荐常用 |
| 双伪元素 | `.clearfix::before, .clearfix::after { content:""; display:table; } .clearfix::after { clear:both; }` | 推荐，可解决外边距塌陷 |
| overflow | 父元素 `overflow: hidden;` | 简单，但内容溢出会被隐藏 |

```css
/* 单伪元素清除浮动（推荐） */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
/* 双伪元素清除浮动 + 防塌陷 */
.clearfix::before,
.clearfix::after {
  content: "";
  display: table;
}
.clearfix::after { clear: both; }
```

### 5.3 定位布局

| `position` | 说明 | 参考系 | 是否脱标 |
| --- | --- | --- | --- |
| `static`（默认） | 静态定位，无定位 | 无 | 否 |
| `relative` | 相对定位 | 自身原来位置 | 否（占位） |
| `absolute` | 绝对定位 | 最近的已定位祖先元素，无则以文档 | 是 |
| `fixed` | 固定定位 | 浏览器视口 | 是 |
| `sticky` | 粘性定位 | 滚动到阈值前相对、阈值后固定 | 否 |

```css
.box {
  position: absolute;
  top: 10px;
  left: 20px;
  z-index: 10;
}
```

**定位口诀：子绝父相**——子元素绝对定位时，父元素一般用相对定位（保留位置 + 提供参考系）。

> ⚠️ 绝对/固定定位元素也具有行内块特性，可直接设置宽高；脱标后不会触发外边距塌陷。

#### 层级 z-index

```css
.box { position: relative; z-index: 2; }
```

- 仅对**已定位**元素（非 static）生效
- 值越大越靠上，可为负
- 同级同 z-index 时，后写者在上

### 5.4 弹性布局 Flex（重点）

```css
.container {
  display: flex;        /* 行内弹性：display: inline-flex; */
}
```

#### 容器属性

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `flex-direction` | 主轴方向 | `row`（默认）/ `row-reverse` / `column` / `column-reverse` |
| `justify-content` | 主轴对齐 | `flex-start` / `center` / `flex-end` / `space-between` / `space-around` / `space-evenly` |
| `align-items` | 交叉轴对齐（单行） | `flex-start` / `center` / `flex-end` / `stretch`（默认）/ `baseline` |
| `flex-wrap` | 是否换行 | `nowrap`（默认）/ `wrap` / `wrap-reverse` |
| `align-content` | 交叉轴对齐（多行） | `flex-start` / `center` / `space-between` / `space-around` / `stretch` |
| `flex-flow` | direction + wrap 简写 | `flex-flow: row wrap;` |

```css
.container {
  display: flex;
  justify-content: space-between; /* 两端对齐，间距相等 */
  align-items: center;            /* 交叉轴居中 */
  flex-wrap: wrap;                /* 允许换行 */
  gap: 10px;                      /* 间距（替代 margin） */
}
```

| `justify-content` | 效果 |
| --- | --- |
| `flex-start` | 起点对齐 |
| `center` | 居中 |
| `flex-end` | 终点对齐 |
| `space-between` | 两端贴边，中间均分 |
| `space-around` | 每个项目两侧间距相等 |
| `space-evenly` | 所有间距完全相等 |

#### 项目属性

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `flex` | `grow shrink basis` 简写 | `flex: 1;`（推荐） |
| `flex-grow` | 放大比例（空间多时分配） | 默认 `0`，`1` 表示均分剩余 |
| `flex-shrink` | 收缩比例（空间不足时压缩） | 默认 `1`，`0` 不收缩 |
| `flex-basis` | 主轴初始尺寸 | 默认 `auto` |
| `align-self` | 单个项目交叉轴对齐 | 覆盖 `align-items` |
| `order` | 排序，值越小越靠前 | 默认 `0` |

```css
.item { flex: 1; }          /* 等分剩余空间 */
.item-main { flex: 2; }     /* 占 2 份 */
.item-side { flex: 0 0 200px; }/* 固定 200px，不放大不收缩 */
.item { align-self: flex-end; }
```

> ⚠️ `flex: 1` 等价于 `flex: 1 1 0%`，表示放大、可收缩、初始尺寸为 0，是均分布局最常用写法。
> ⚠️ 设为 flex 容器后，子元素的 `float`、`vertical-align`、`clear` 失效。

### 5.5 网格布局 Grid

```css
.container {
  display: grid;
  grid-template-columns: 100px 1fr 2fr; /* 三列：固定 1 自由 2 倍 */
  grid-template-columns: repeat(3, 1fr); /* 3 列等宽 */
  grid-template-rows: 60px auto;
  gap: 10px 20px;             /* 行间距 列间距 */
  justify-items: center;      /* 单元格内水平对齐 */
  align-items: center;        /* 单元格内垂直对齐 */
}
```

| 属性 | 说明 |
| --- | --- |
| `grid-template-columns` | 定义列宽，可用 `fr`（比例）、`px`、`auto`、`repeat(n, val)` |
| `grid-template-rows` | 定义行高 |
| `gap` / `row-gap` / `column-gap` | 间距 |
| `justify-items` | 子元素水平对齐：`start/center/end/stretch` |
| `align-items` | 子元素垂直对齐：`start/center/end/stretch` |
| `justify-content` | 整个网格在容器中水平对齐 |
| `align-content` | 整个网格在容器中垂直对齐 |

```css
/* 项目跨越多个单元格 */
.item {
  grid-column: 1 / 3;   /* 跨第 1~2 列 */
  grid-row: 1 / 2;      /* 占第 1 行 */
}
```

### 5.6 多栏布局 column

类似报纸分栏排版。

| 属性 | 说明 |
| --- | --- |
| `column-count` | 栏数 |
| `column-width` | 每栏宽度 |
| `column-gap` | 栏间距 |
| `column-rule` | 分隔线（同 border 写法） |
| `break-inside: avoid` | 防止内容跨栏断开 |

```css
.article {
  column-count: 3;
  column-gap: 30px;
  column-rule: 1px solid #ccc;
}
.item { break-inside: avoid; } /* 瀑布流常用 */
```

## 六、变形 Transform

> ⚠️ transform 不会脱离文档流，不改变其他元素布局；变形后元素仍占据原位置。

### 6.1 2D 变换

```css
transform: translate(50px, 20px); /* 平移：x, y */
transform: rotate(45deg);         /* 旋转：顺时针为正 */
transform: scale(1.5);            /* 缩放：1.5 倍，可用 scale(x,y) */
transform: skew(15deg, 10deg);    /* 倾斜：x, y */
transform-origin: left top;       /* 变换原点：默认 center center */
```

| 函数 | 说明 |
| --- | --- |
| `translate(x, y)` | 平移，可写百分比（相对自身） |
| `translateX()` / `translateY()` | 单方向平移 |
| `rotate(deg)` | 旋转，单位 `deg` |
| `scale(n)` | 缩放，`scale(2)` 放大 2 倍 |
| `skew(x, y)` | 倾斜 |

```css
/* 多组变换连写，空格分隔，从右向左执行 */
.box { transform: translate(100px, 0) rotate(45deg) scale(1.2); }
```

> ⚠️ `translate` 相对自身百分比平移，是**绝对居中**的常用方案：
> ```css
> .box { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
> ```

### 6.2 3D 变换

```css
transform: rotateX(45deg);    /* 绕 X 轴旋转 */
transform: rotateY(45deg);    /* 绕 Y 轴旋转 */
transform: rotateZ(45deg);    /* 绕 Z 轴（同 2D rotate） */
transform: translateZ(100px); /* Z 轴平移（需透视才生效） */
```

**透视 perspective**：设置在**父元素**上，决定 3D 效果的强度（值越小越夸张）。

```css
.scene {
  perspective: 800px;        /* 父元素透视 */
  transform-style: preserve-3d; /* 子元素保留 3D 空间 */
}
.card {
  transform: rotateY(180deg);
  backface-visibility: hidden; /* 隐藏背面（翻转卡片常用） */
}
```

| 属性 | 说明 |
| --- | --- |
| `perspective` | 透视距离（设在父元素） |
| `transform-style: preserve-3d` | 让子元素处于 3D 空间（默认 `flat`） |
| `backface-visibility: hidden` | 背面是否可见 |

> ⚠️ 翻转卡片效果必三件套：父元素 `perspective` + `transform-style: preserve-3d` + 子元素 `backface-visibility: hidden`。

## 七、过渡与动画

### 7.1 过渡 transition

> ⚠️ transition 只能在两个状态间过渡，需要触发条件（如 hover）。常配合 `transform` 实现动画。

```css
transition: property duration timing-function delay;
```

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `transition-property` | 过渡的属性 | `all` / `width` / `transform` |
| `transition-duration` | 持续时间 | `0.3s` |
| `transition-timing-function` | 时间函数 | `ease` / `linear` / `ease-in` / `ease-out` / `ease-in-out` / `cubic-bezier()` |
| `transition-delay` | 延迟时间 | `0s` |

```css
.box {
  transition: all 0.3s ease;  /* 推荐：写在原状态里 */
}
.box:hover { transform: scale(1.1); }
```

> ⚠️ transition 必须写在**初始状态**（不是 hover 状态），否则回退时没有过渡效果。

### 7.2 动画 animation

**`@keyframes` 定义关键帧：**

```css
@keyframes move {
  0%   { transform: translateX(0); }
  50%  { transform: translateX(200px); }
  100% { transform: translateX(0); }
}
/* 简写：from 等价于 0%，to 等价于 100% */
@keyframes fade {
  from { opacity: 0; }
  to   { opacity: 1; }
}
```

**animation 简写：**

```css
animation: name duration timing-function delay iteration-count direction fill-mode;
```

| 属性 | 说明 | 常见值 |
| --- | --- | --- |
| `animation-name` | 关键帧名称 | `move` |
| `animation-duration` | 持续时间 | `1s` |
| `animation-timing-function` | 时间函数 | `ease` / `linear` / `steps(n)` |
| `animation-delay` | 延迟 | `0s` |
| `animation-iteration-count` | 播放次数 | `1`（默认）/ `infinite`（无限） |
| `animation-direction` | 方向 | `normal` / `reverse` / `alternate`（交替）/ `alternate-reverse` |
| `animation-fill-mode` | 填充模式 | `none` / `forwards`（停在 100%）/ `backwards` / `both` |
| `animation-play-state` | 播放状态 | `running`（默认）/ `paused` |

```css
.box {
  animation: move 2s ease infinite alternate;
}
.box:hover {
  animation-play-state: paused; /* 鼠标悬停暂停 */
}
```

> ⚠️ `steps(n)` 实现分步动画（如精灵图走路动画）；`forwards` 让动画停在最后一帧。

## 八、前沿特性

### 8.1 SVG

SVG（可缩放矢量图形）：基于 XML 描述矢量图形，放大不失真，文件小。

#### 基本形状

| 标签 | 说明 |
| --- | --- |
| `<rect>` | 矩形 |
| `<circle>` | 圆形 |
| `<ellipse>` | 椭圆 |
| `<line>` | 直线 |
| `<polyline>` | 折线 |
| `<polygon>` | 多边形 |
| `<path>` | 路径（最强大） |

```html
<svg width="100" height="100" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" stroke="#000" stroke-width="2" fill="red" />
  <path d="M10 10 L90 90" stroke="#000" fill="none" />
</svg>
```

#### path 常用命令

| 命令 | 说明 |
| --- | --- |
| `M x y` | 移动到 |
| `L x y` | 直线到 |
| `H x` / `V y` | 水平 / 垂直直线 |

| `Q x1 y1, x y` | 二次贝塞尔 |
| `Z` | 闭合路径 |

#### 描边动画

```css
.path {
  stroke-dasharray: 1000;   /* 虚线长度（设为路径总长） */
  stroke-dashoffset: 1000;  /* 偏移量（隐藏） */
  animation: draw 3s ease forwards;
}
@keyframes draw {
  to { stroke-dashoffset: 0; } /* 偏移归零，路径绘制完成 */
}
```

| 属性 | 说明 |
| --- | --- |
| `stroke-dasharray` | 定义虚线段长度 |
| `stroke-dashoffset` | 虚线偏移量 |

### 8.2 clip-path 裁剪

裁剪元素的可视区域。

```css
.clip {
  clip-path: circle(50% at 50% 50%);          /* 圆形 */

  clip-path: inset(10px 20px 10px 20px);      /* 内缩矩形 */
}
```

**配合背景做文字裁剪：**

```css
.text-clip {

  -webkit-background-clip: text;
  color: transparent;
}
```

### 8.3 CSS 滤镜 filter

| 值 | 说明 |
| --- | --- |
| `blur(px)` | 高斯模糊 |
| `brightness(n)` | 亮度（1 原样，>1 变亮） |
| `contrast(n)` | 对比度 |
| `grayscale(n)` | 灰度（1 全灰） |
| `sepia(n)` | 复古褐 |
| `saturate(n)` | 饱和度 |

## 九、CSS 初始化与最佳实践

### 9.1 常见浏览器默认样式重置

不同浏览器对部分标签有默认 margin、padding、字号，需统一。

```css
/* 通用基础重置 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font: 14px/1.5 "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
  color: #333;
}

/* 去除列表默认样式 */
ul, ol { list-style: none; }

/* 去除链接默认下划线 */
a { text-decoration: none; color: #333; }

/* 去除图片默认间隙与边框 */
img { display: block; border: 0; vertical-align: middle; }

/* 清除 input 默认样式 */
input, button { outline: none; border: none; }

/* 标题恢复默认字号 */
h1, h2, h3, h4, h5, h6 { font-weight: normal; font-size: 100%; }
```

> ⚠️ 也可使用成熟的 `Normalize.css`，它保留有用默认值并修复浏览器差异，比 reset 更温和。

### 9.2 精灵图（Sprite）与字体图标（iconfont）

#### 精灵图

将多个小图标合并成一张大图，通过 `background-position` 定位显示所需部分。

**优点：** 减少 HTTP 请求数，降低服务器压力。

```css
.icon {
  width: 20px; height: 20px;
  background: url("sprite.png") no-repeat;
}
.icon-home { background-position: 0 0; }
.icon-user { background-position: -20px 0; }
```

> ⚠️ 坐标用负值（向左上移动背景图）。

#### 字体图标（iconfont）

用字体文件承载矢量图标，可像文字一样设置颜色、大小，放大不失真。

**优点：** 矢量、体积小、可改色、支持 CSS 文字样式。

```html
<link rel="stylesheet" href="./iconfont/iconfont.css">
<i class="iconfont icon-home"></i>
```

```css
.iconfont { font-family: "iconfont"; }
.icon-home::before { content: "\e001"; }
```

> ⚠️ 精灵图主要用于位图（如设计稿切图），矢量图标优先使用字体图标或 SVG。

## 💡 关联面试题

**Q1：CSS 盒模型是什么？标准盒模型和怪异盒模型区别？**

盒模型由 content（内容）、padding（内边距）、border（边框）、margin（外边距）四部分组成。
- **标准盒模型**（`box-sizing: content-box`，默认）：`width` 只包含 content，实际占用宽度 = width + padding + border + margin
- **怪异盒模型**（`box-sizing: border-box`）：`width` 包含 content + padding + border，实际占用宽度 = width + margin

> 实际开发中通常全局设置 `box-sizing: border-box`，便于尺寸计算。

**Q2：如何实现元素水平垂直居中？（至少3种方式）**

```css
/* 方式一：定位 + transform（推荐，无需知道宽高） */
.box {
  position: absolute; top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}

/* 方式二：定位 + margin auto（需有宽高） */
.box {
  position: absolute; top: 0; right: 0; bottom: 0; left: 0;
  margin: auto;
}

/* 方式三：Flex（推荐，父元素设置） */
.parent { display: flex; justify-content: center; align-items: center; }

/* 方式四：Grid */
.parent { display: grid; place-items: center; }

/* 方式五：定位 + 负 margin（需知道具体宽高） */
.box {
  position: absolute; top: 50%; left: 50%;
  margin-top: -50px; margin-left: -50px; /* 自身宽高的一半 */
}
```

**Q3：Flex 布局中 justify-content 和 align-items 的作用？**

- `justify-content`：定义主轴方向上的对齐方式（如 `flex-start/center/space-between`）
- `align-items`：定义交叉轴方向上的对齐方式（如 `center/stretch`）

> 主轴方向由 `flex-direction` 决定。默认 `row` 时主轴为水平方向，此时 justify-content 控制水平对齐、align-items 控制垂直对齐；改为 `column` 后两者交换。

**Q4：说说 CSS 选择器优先级如何计算？**

优先级从高到低：`!important` > 行内 `style` > `id` > 类/伪类/属性 > 标签/伪元素 > 通配符。

特异性用 (a, b, c) 三元组表示：a 为 id 数、b 为类/伪类/属性 数、c 为标签/伪元素 数，从左到右比较，权值不可进位（10 个类仍小于 1 个 id）。`!important` 优先于普通声明，相同优先级时后写的覆盖先写的。

**Q5：清除浮动有哪些方式？各自优缺点？**

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| 额外标签法 | 简单直观 | 添加无语义标签 |
| 单伪元素法 | 无多余 DOM | 不能解决外边距塌陷 |
| 双伪元素法 | 无多余 DOM，兼除塌陷 | 写法略复杂 |
| `overflow: hidden` | 一行搞定 | 溢出内容会被裁切 |

> 推荐双伪元素法，是主流框架（如 Bootstrap）采用的方案。

**Q6：position 的值有哪些？各自特点？**

| 值 | 特点 |
| --- | --- |
| `static` | 默认，无定位，不脱离文档流 |
| `relative` | 相对自身原位置偏移，**保留原位置** |
| `absolute` | 相对最近的已定位祖先元素，脱标，不保留位置 |
| `fixed` | 相对浏览器视口，脱标，滚动时不移动 |
| `sticky` | 未达阈值按 relative，达到阈值按 fixed，需指定 top/left 等阈值 |

> 常用口诀：**子绝父相**——子元素绝对定位时父元素用相对定位提供参考系并保留位置。

**Q7：transition 和 animation 的区别？**

| 对比项 | transition | animation |
| --- | --- | --- |
| 触发方式 | 需要触发条件（如 hover） | 可自动执行 |
| 状态数 | 两个状态之间过渡 | 可定义多个关键帧 |
| 循环 | 不支持 | 支持 `infinite` |
| 暂停 | 不支持 | 支持 `animation-play-state: paused` |
| 方向控制 | 不支持 | 支持 `alternate` 交替 |

> 简单两态过渡用 transition，复杂连续动画用 animation。
