# Vue3 最新全面复习

> 本文档基于 Vue 3 最新版本（含 3.4 / 3.5 / 3.6 Vapor Mode）系统整理，涵盖组合式 API、响应式系统原理、新增宏与 Hooks、组件通信、内置组件、Vue Router、Pinia、Vite 工程化、性能优化及前沿特性。

## 一、Vue3 概述与版本演进

### 1.1 Vue3 核心变化

| 特性 | Vue2 | Vue3 |
| --- | --- | --- |
| API 风格 | 选项式 API（Options API） | 组合式 API（Composition API） |
| 响应式原理 | `Object.defineProperty` | `Proxy` |
| 模板 | 单根节点 | 多根节点（Fragment） |
| TypeScript | 支持较弱 | 原生支持 |
| Tree-shaking | 不支持 | 支持（按需引入） |
| 性能 | 一般 | 提升 1.3~2 倍 |
| 内置新组件 | - | Teleport、Suspense |

### 1.2 版本演进时间线

| 版本 | 重要特性 |
| --- | --- |
| 3.0 | 组合式 API、Proxy 响应式、Fragment、Teleport、Suspense |
| 3.2 | `<script setup>` 正式发布、CSS v-bind、状态驱动的动态 CSS |
| 3.3 | 泛型组件、defineSlots、defineModel（实验性） |
| 3.4 | defineModel 正式转正、模板解析器重写、defineProps 解构增强 |
| 3.5 | 响应式 props 解构转正、useTemplateRef、useId、watch 增强 |
| 3.6 | **Vapor Mode（蒸汽模式）功能完备**，无虚拟 DOM 编译 |

## 二、组合式 API 与 `<script setup>`

### 2.1 setup 函数

```javascript
import { ref, onMounted } from 'vue'

export default {
  setup(props, context) {
    // props：组件传入的属性
    // context：{ attrs, slots, emit, expose }
    const count = ref(0)
    const increment = () => count.value++

    onMounted(() => {
      console.log('组件已挂载')
    })

    // 必须返回模板中使用的变量和方法
    return { count, increment }
  }
}
```

### 2.2 `<script setup>` 语法糖（推荐）

```vue
<script setup>
import { ref, onMounted } from 'vue'

const count = ref(0)
const increment = () => count.value++

onMounted(() => {
  console.log('组件已挂载')
})
// 顶层变量自动暴露给模板，无需 return
</script>

<template>
  <button @click="increment">{{ count }}</button>
</template>
```

| 对比 | setup() 函数 | `<script setup>` |
| --- | --- | --- |
| 代码量 | 多（需 return） | 少（自动暴露） |
| 性能 | 一般 | 更好（编译优化） |
| 组件引入 | 需注册 components | 直接使用 |
| TS 支持 | 一般 | 更好 |
| 推荐度 | 旧项目迁移 | **新项目首选** |

### 2.3 defineProps 与 defineEmits

```vue
<script setup>
// defineProps：声明 props
const props = defineProps({
  msg: String,
  count: { type: Number, default: 0 }
})

// TypeScript 泛型写法（推荐）
const props = defineProps<{
  msg: string
  count?: number
}>()

// 带默认值的 TS 写法（Vue 3.5 推荐解构默认值）
const { msg, count = 0 } = defineProps<{
  msg: string
  count?: number
}>()

// defineEmits：声明事件
const emit = defineEmits(['update', 'delete'])
emit('update', newValue)
</script>
```

> ⚠️ `defineProps`、`defineEmits`、`defineExpose`、`defineModel`、`defineOptions`、`defineSlots` 都是**编译器宏**，无需 import，只能在 `<script setup>` 中使用。

### 2.4 defineExpose

`<script setup>` 默认不暴露组件实例，需用 `defineExpose` 显式暴露。

```vue
<!-- 子组件 Child.vue -->
<script setup>
import { ref } from 'vue'
const count = ref(0)
const reset = () => { count.value = 0 }

defineExpose({ count, reset })
</script>

<!-- 父组件 -->
<script setup>
import { ref, onMounted } from 'vue'
import Child from './Child.vue'

const childRef = ref()
onMounted(() => {
  console.log(childRef.value.count) // 访问子组件数据
  childRef.value.reset()            // 调用子组件方法
})
</script>

<template>
  <Child ref="childRef" />
</template>
```

### 2.5 defineOptions（Vue 3.3+）

在 `<script setup>` 中定义组件选项（name、inheritAttrs 等）。

```vue
<script setup>
defineOptions({
  name: 'MyComponent',
  inheritAttrs: false
})
</script>
```

### 2.6 defineModel（Vue 3.4 正式版）

大幅简化父子组件双向绑定（v-model）。

```vue
<!-- 子组件 MyInput.vue（Vue 3.4+ 推荐写法） -->
<script setup>
const model = defineModel<string>()  // 自动绑定 v-model
const updateValue = (e) => {
  model.value = e.target.value
}
</script>

<template>
  <input :value="model" @input="updateValue" />
</template>

<!-- 父组件 -->
<template>
  <MyInput v-model="msg" />
</template>
```

#### 多个 v-model

```vue
<script setup>
const firstName = defineModel('firstName')
const lastName = defineModel('lastName')
</script>

<!-- 父组件 -->
<template>
  <UserForm v-model:firstName="fn" v-model:lastName="ln" />
</template>
```

## 三、响应式系统（核心）

### 3.1 ref

`ref` 用于基本类型和引用类型，访问时需 `.value`。

```javascript
import { ref } from 'vue'

const count = ref(0)        // 数字
const msg = ref('hello')    // 字符串
const user = ref({ name: '张三' }) // 对象

console.log(count.value)    // 0
count.value++               // 修改
user.value.name = '李四'    // 修改对象属性
```

> 💡 模板中 ref 自动解包，无需 `.value`：`{{ count }}`

### 3.2 reactive

`reactive` 仅用于对象/数组，直接访问属性，无需 `.value`。

```javascript
import { reactive } from 'vue'

const state = reactive({
  count: 0,
  user: { name: '张三' }
})

state.count++               // 直接修改
state.user.name = '李四'
```

> ⚠️ **易错点**：不能整体替换 reactive 对象（会丢失响应式），应使用 `Object.assign(state, newObj)` 逐个覆盖属性。

### 3.3 ref vs reactive

| 对比 | ref | reactive |
| --- | --- | --- |
| 适用类型 | 所有类型 | 仅对象/数组 |
| 访问方式 | 需 `.value` | 直接访问 |
| 模板解包 | 自动解包 | 直接使用 |
| 整体替换 | 可以 | 不可以（丢失响应式） |
| 解构 | 不丢失响应式 | 丢失响应式（需 toRefs） |
| 推荐场景 | 基本类型、需替换的对象 | 固定结构的对象 |

### 3.4 toRefs 与 toRef

将 reactive 对象的属性解构为 ref，保持响应式。

```javascript
import { reactive, toRefs, toRef } from 'vue'

const state = reactive({ name: '张三', age: 18 })

// 解构会丢失响应式：
// const { name, age } = state  // ❌

// 正确方式：toRefs 解构所有属性
const { name, age } = toRefs(state)
console.log(name.value)  // '张三'

// toRef 解构单个属性
const nameRef = toRef(state, 'name')
```

### 3.5 响应式 Props 解构（Vue 3.5 正式版）

Vue 3.5 之前，解构 `defineProps` 会丢失响应式。3.5 起编译器自动处理，解构后保持响应式。

```vue
<script setup>
// Vue 3.5+ ✅ 直接解构，保持响应式
const { count = 0, msg = 'hello' } = defineProps<{
  count?: number
  msg?: string
}>()

// watch 可以直接监听解构后的变量
watch(count, (newVal) => {
  console.log('count 变化：', newVal)
})
</script>
```

```vue
<!-- Vue 3.5 之前的写法（已过时） -->
<script setup>
const props = defineProps<{ count?: number; msg?: string }>()

// 必须用 withDefaults 设置默认值
const { count, msg } = withDefaults(props, { count: 0, msg: 'hello' })
// ❌ 这样解构会丢失响应式
</script>
```

### 3.6 响应式原理（Vue 3.5 重构）

Vue 3.5 对响应式系统进行了重大重构：

| 改进 | 说明 |
| --- | --- |
| 版本计数（Version Counting） | 每个依赖维护版本号，减少不必要的更新 |
| 双向链表结构 | 依赖收集从树结构改为链表（灵感来自 Preact Signals） |
| 内存优化 | 内存占用降低约 60% |
| 计算属性优化 | 减少不必要的重新计算 |

```
Proxy 拦截 → track（收集依赖）→ effect（副作用）→ trigger（触发更新）
```

### 3.7 shallowRef 与 shallowReactive

浅层响应式，只对第一层响应式。

```javascript
import { shallowRef, shallowReactive, triggerRef } from 'vue'

// shallowRef：只有 .value 变化才触发更新
const state = shallowRef({ count: 0 })
state.value.count = 1     // ❌ 不触发更新
state.value = { count: 1 } // ✅ 触发更新
triggerRef(state)          // ✅ 手动触发

// shallowReactive：只有根级属性响应式
const obj = shallowReactive({ nested: { count: 0 } })
obj.nested.count = 1      // ❌ 不触发
obj.count = 1              // ✅ 触发
```

> 💡 适用场景：大型数据结构（如 ECharts 配置）优化性能。

### 3.8 readonly 与 shallowReadonly

```javascript
import { readonly, reactive } from 'vue'

const original = reactive({ count: 0 })
const copy = readonly(original)
// copy.count = 1  // ❌ 警告：只读
```

### 3.9 markRaw

永久标记对象不转为响应式。

```javascript
import { reactive, markRaw } from 'vue'

const config = markRaw({ animation: () => { ... } })
const state = reactive({ config })  // config 不会被代理
```

### 3.10 customRef

自定义 ref，控制依赖追踪和触发。

```javascript
import { customRef } from 'vue'

// 防抖 ref
function debouncedRef(value, delay = 200) {
  let timer
  return customRef((track, trigger) => ({
    get() {
      track()
      return value
    },
    set(newValue) {
      clearTimeout(timer)
      timer = setTimeout(() => {
        value = newValue
        trigger()
      }, delay)
    }
  }))
}

const keyword = debouncedRef('', 300)
```

## 四、计算属性与侦听器

### 4.1 computed

```javascript
import { ref, computed } from 'vue'

const count = ref(1)

// 只读计算属性
const double = computed(() => count.value * 2)

// 可读可写计算属性
const fullName = computed({
  get: () => `${firstName.value} ${lastName.value}`,
  set: (newValue) => {
    [firstName.value, lastName.value] = newValue.split(' ')
  }
})
```

### 4.2 watch

```javascript
import { ref, watch, reactive } from 'vue'

const count = ref(0)
const state = reactive({ user: { name: '张三' } })

// 1. 监听 ref
watch(count, (newVal, oldVal) => {
  console.log(newVal, oldVal)
})

// 2. 监听 reactive 属性（需用函数返回）
watch(
  () => state.user.name,
  (newVal, oldVal) => { console.log(newVal) }
)

// 3. 深度监听 + 立即执行
watch(
  () => state.user,
  (newVal) => { console.log('深度监听', newVal) },
  { deep: true, immediate: true }
)

// 4. 监听多个源
watch([count, () => state.user.name], ([newCount, newName]) => {
  console.log(newCount, newName)
})

// 5. Vue 3.5 新增：once（只监听一次）
watch(count, (val) => {
  console.log('只触发一次：', val)
}, { once: true })
```

### 4.3 watch 选项

| 选项 | 说明 | 默认值 |
| --- | --- | --- |
| `deep` | 深度监听对象内部变化 | `false` |
| `immediate` | 立即执行回调 | `false` |
| `flush` | 触发时机：`pre`/`post`/`sync` | `'pre'` |
| `once` | 只触发一次（Vue 3.5+） | `false` |

### 4.4 watch 的暂停与恢复（Vue 3.5+）

```javascript
const { stop, pause, resume } = watch(count, (val) => {
  console.log(val)
})

pause()  // 暂停监听
resume() // 恢复监听
stop()   // 停止监听
```

### 4.5 watchEffect

```javascript
import { watchEffect, ref } from 'vue'

const count = ref(0)
const name = ref('张三')

// 自动收集依赖，立即执行
watchEffect(() => {
  console.log(count.value, name.value) // 自动追踪 count 和 name
})

// 副作用清理
watchEffect((onCleanup) => {
  const timer = setTimeout(() => {
    console.log('fetch data', count.value)
  }, 300)
  onCleanup(() => clearTimeout(timer)) // 清除上一次的定时器
})
```

### 4.6 watch vs watchEffect

| 对比 | watch | watchEffect |
| --- | --- | --- |
| 依赖收集 | 显式指定 | 自动收集 |
| 初始执行 | 默认不执行（immediate 控制） | 立即执行 |
| 旧值 | 能获取 | 不能获取 |
| 适用 | 需要旧值、精确控制 | 副作用、自动追踪 |

## 五、生命周期

### 5.1 生命周期钩子

| Vue2 | Vue3（Options API） | Vue3（Composition API） | 说明 |
| --- | --- | --- | --- |
| beforeCreate | beforeCreate | `setup()` | 创建前 |
| created | created | `setup()` | 创建后 |
| beforeMount | beforeMount | `onBeforeMount` | 挂载前 |
| mounted | mounted | `onMounted` | 挂载完成 |
| beforeUpdate | beforeUpdate | `onBeforeUpdate` | 更新前 |
| updated | updated | `onUpdated` | 更新完成 |
| beforeDestroy | beforeUnmount | `onBeforeUnmount` | 卸载前 |
| destroyed | unmounted | `onUnmounted` | 卸载完成 |
| - | errorCaptured | `onErrorCaptured` | 捕获错误 |
| - | activated | `onActivated` | KeepAlive 激活 |
| - | deactivated | `onDeactivated` | KeepAlive 停用 |

### 5.2 使用示例

```vue
<script setup>
import { onMounted, onUpdated, onUnmounted } from 'vue'

onMounted(() => {
  console.log('组件已挂载，可访问 DOM')
})

onUpdated(() => {
  console.log('组件更新完成')
})

onUnmounted(() => {
  console.log('组件卸载，清理定时器/事件')
```

### 6.5 模板引用 useTemplateRef（Vue 3.5+）

Vue 3.5 新增 `useTemplateRef`，比传统 ref 更语义化、类型安全。

```vue
<!-- 旧写法（Vue 3.4 及之前） -->
<script setup>
import { ref } from 'vue'
const inputEl = ref<HTMLInputElement>()  // ref 既是响应式数据又可能是 DOM
</script>
<template>
  <input ref="inputEl" />
</template>

<!-- 新写法（Vue 3.5+ 推荐） -->
<script setup>
import { useTemplateRef } from 'vue'
const inputEl = useTemplateRef<HTMLInputElement>('inputEl') // 参数是模板中 ref 字符串
</script>
<template>
  <input ref="inputEl" />
</template>
```

| 对比 | 传统 ref | useTemplateRef |
| --- | --- | --- |
| 语义 | 模糊（数据 or DOM？） | 明确（获取模板元素） |
| 类型推断 | 一般 | 更好 |
| 命名冲突 | 同名变量会冲突 | 字符串隔离 |

### 6.6 provide / inject

```vue
<!-- 祖先组件 -->
<script setup>
import { provide, ref } from 'vue'
const theme = ref('dark')
const user = ref({ name: '张三' })

provide('theme', theme)       // 提供响应式数据
provide('user', user)
provide('updateUser', (newUser) => { user.value = newUser }) // 提供方法
</script>

<!-- 后代组件（任意层级） -->
<script setup>
import { inject } from 'vue'
const theme = inject('theme', 'light')  // 第二个参数是默认值
const user = inject('user')
const updateUser = inject('updateUser')
</script>
```

> ⚠️ 直接修改 inject 的 reactive 数据会破坏单向数据流，推荐通过 provide 方法修改。

## 七、内置组件

### 7.1 Teleport（传送门）

将组件内容渲染到 DOM 的指定位置。

```vue
<script setup>
import { ref } from 'vue'
const visible = ref(false)
</script>

<template>
  <button @click="visible = true">打开弹窗</button>

  <!-- teleport to：指定挂载目标 -->
  <Teleport to="body">
    <div v-if="visible" class="modal">
      <h2>弹窗内容</h2>
      <button @click="visible = false">关闭</button>
    </div>
  </Teleport>
</template>
```

> ⚠️ Teleport 的 `to` 属性必须是有效的 CSS 选择器或 DOM 元素。

### 7.2 Suspense（异步组件）

协调异步组件的加载状态。

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

const AsyncComp = defineAsyncComponent(() => import('./Heavy.vue'))
</script>

<template>
  <Suspense>
    <!-- 默认内容 -->
    <template #default>
      <AsyncComp />
    </template>
    <!-- 加载中 -->
    <template #fallback>
      <div>Loading...</div>
    </template>
  </Suspense>
</template>
```

### 7.3 KeepAlive

缓存组件状态，避免重复渲染。

```vue
<template>
  <KeepAlive :include="['UserList', 'UserDetail']" :max="10">
    <component :is="currentComponent" />
  </KeepAlive>
</template>
```

| 属性 | 说明 |
| --- | --- |
| `include` | 缓存指定组件（名称匹配） |
| `exclude` | 不缓存指定组件 |
| `max` | 最大缓存数量（LRU 淘汰） |

配套生命周期：`onActivated`（激活）、`onDeactivated`（停用）。

### 7.4 Transition / TransitionGroup

```vue
<template>
  <Transition name="fade">
    <div v-if="visible">内容</div>
  </Transition>
</template>

<style>
.fade-enter-active, .fade-leave-active {
  transition: opacity 0.3s;
}
.fade-enter-from, .fade-leave-to {
  opacity: 0;
}
</style>
```

### 8.2 v-model 变化（Vue3）

```vue
<!-- Vue2: value + input -->
<!-- Vue3: modelValue + update:modelValue -->

<!-- 组件上使用 -->
<MyInput v-model="msg" />
<!-- 等价于 -->
```

### 12.1 什么是组合式函数

### 12.2 自定义组合式函数

```javascript
// composables/useMouse.js
import { ref, onMounted, onUnmounted } from 'vue'

export function useMouse() {
  const x = ref(0)
  const y = ref(0)

  const update = (e) => {
    x.value = e.pageX
    y.value = e.pageY
  }

  onMounted(() => window.addEventListener('mousemove', update))
  onUnmounted(() => window.removeEventListener('mousemove', update))

  return { x, y }
}

// 使用
```

### 12.3 常用组合式函数封装

```javascript
// useFetch - 数据请求
import { ref, watchEffect } from 'vue'

export function useFetch(url) {
  const data = ref(null)
  const error = ref(null)
  const loading = ref(false)

  const doFetch = async () => {
    loading.value = true
    error.value = null
    try {
      const res = await fetch(url.value)
      data.value = await res.json()
    } catch (err) {
      error.value = err
    } finally {
      loading.value = false
    }
  }

  watchEffect(doFetch)  // url 变化自动重新请求
  return { data, error, loading, refresh: doFetch }
}

// useLocalStorage - 本地存储
import { ref, watch } from 'vue'

export function useLocalStorage(key, defaultValue) {
  const value = ref(localStorage.getItem(key) || defaultValue)
  watch(value, (newVal) => {
    localStorage.setItem(key, newVal)
  })
  return value
}
```

## 十四、Vapor Mode（Vue 3.6+ 前沿特性）

### 14.1 什么是 Vapor Mode

Vapor Mode（蒸汽模式）是 Vue 3.6 引入的**无虚拟 DOM** 编译模式，通过编译时静态分析直接生成高效的 DOM 操作代码，性能直逼 SolidJS。

### 14.2 Vapor Mode 核心原理

```
传统模式：模板 → 渲染函数 → 虚拟 DOM → Diff → 真实 DOM
Vapor 模式：模板 → 编译时分析 → 直接 DOM 操作代码（无虚拟 DOM）
```

| 特性 | 传统模式 | Vapor Mode |
| --- | --- | --- |
| 虚拟 DOM | 有 | **无** |
| 运行时体积 | 较大 | 更小 |
| 性能 | 好 | **极快**（接近原生） |
| 内存 | 较高 | 降低约 60% |
| 依赖追踪 | - | 减少约 40% |
| 兼容性 | 完整 | 子集（功能完备） |

### 14.3 使用 Vapor 组件

```vue
<!-- MyComponent.vue -->
<script setup vapor>
// 添加 vapor 标识，启用 Vapor 模式编译
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

### 14.4 Vapor Mode 的限制

- 部分高级特性可能不支持
- 虚拟组件和普通组件可以混用
- 主要针对性能敏感场景

> 💡 Vapor Mode 适合性能要求极高的场景，如高频更新的列表、动画密集型应用。

## 十八、Vue3 响应式源码原理

### 18.1 Proxy 响应式核心

```javascript
// 简化版响应式原理
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      track(target, key)  // 收集依赖
      return Reflect.get(target, key, receiver)
    },
    set(target, key, value, receiver) {
      const result = Reflect.set(target, key, value, receiver)
      trigger(target, key)  // 触发更新
      return result
    }
  })
}
```

### 18.2 ref 原理

```javascript
// 简化版 ref
function ref(value) {
  return {
    get value() {
      track(this, 'value')
      return value
    },
    set value(newVal) {
      value = newVal
      trigger(this, 'value')
    }
  }
}
```

### 18.3 Vue 3.5 响应式重构

| 改进 | 说明 |
| --- | --- |
| 版本计数 | 每个依赖有版本号，对比版本判断是否需要更新 |
| 双向链表 | 依赖关系用链表存储，遍历更快 |
| 内存优化 | 减少对象创建，内存降低 60% |
| 计算属性 | 避免不必要的重新计算 |

- Vapor Mode（3.6+）无虚拟 DOM

**Q2：ref 和 reactive 的区别？**
- ref 适用所有类型，需 `.value` 访问
- reactive 仅适用对象/数组，直接访问
- ref 可整体替换，reactive 不行
- reactive 解构会丢失响应式，需 toRefs

**Q3：Vue 3.5 响应式 props 解构是什么？**
- 3.5 之前解构 defineProps 会丢失响应式
- 3.5 编译器自动处理，解构后保持响应式
- 可以直接设置默认值：`const { count = 0 } = defineProps(...)`
- watch 可以直接监听解构后的变量

**Q4：defineModel 的作用？（Vue 3.4+）**
- 简化父子组件 v-model 双向绑定
- 替代 props + emit 的繁琐写法
- 支持多个 v-model（命名 model）
- Vue 3.4 正式转正

**Q5：useTemplateRef 和传统 ref 模板引用的区别？（Vue 3.5+）**
- useTemplateRef 语义明确，专门获取模板元素
- 类型推断更好
- 避免与响应式 ref 变量混淆
- 参数是字符串，与模板 ref 属性对应

**Q6：Vue3 的编译优化有哪些？**
- 静态提升：静态节点提取到 render 外
- PatchFlag：动态节点标记，Diff 时只比较动态部分
- BlockTree：将动态节点收集到 Block
- 缓存事件处理器
- Tree-shaking 按需打包

**Q7：Pinia 相比 Vuex 有什么优势？**
- 无 mutations，直接修改 state
- 完美的 TypeScript 支持
- 每个 store 独立，无需模块嵌套
- 支持 Composition API 风格（Setup Store）
- 体积更小（约 1KB）
- 原生支持 HMR 和 SSR

**Q8：Vapor Mode 是什么？（Vue 3.6+）**
- 无虚拟 DOM 的编译模式
- 编译时直接生成 DOM 操作代码
- 性能接近原生，内存降低 60%
- 依赖追踪减少 40%
- 可与虚拟组件混用

**Q9：Vue3 中如何做性能优化？**
- 使用 shallowRef/shallowReactive 处理大对象
- v-memo 列表记忆化
- v-once 只渲染一次
- 路由懒加载
- KeepAlive 缓存组件
- 异步组件 + Suspense
- 虚拟列表（useVirtualList）
- markRaw 跳过响应式

**Q10：组合式函数（Composables）是什么？**
- 以 use 开头的函数，封装可复用逻辑
- 类似 React Hooks
- 可组合多个逻辑单元
- 社区有 VueUse 提供大量现成函数
- 优于 Vue2 的 mixins（无命名冲突、来源清晰）

**Q11：Vue3 的响应式原理是什么？**
- 基于 Proxy 代理对象
- get 时 track 收集依赖
- set 时 trigger 触发更新
- Vue 3.5 引入版本计数和双向链表优化
- ref 本质是对象属性 get/set 的封装

**Q12：Vue Router 4 的新特性？**
- createRouter / createWebHistory API
- 动态路由 addRoute
- 组合式 API：useRouter、useRoute
- 组件内守卫：onBeforeRouteLeave、onBeforeRouteUpdate
- 更好的 TypeScript 支持
