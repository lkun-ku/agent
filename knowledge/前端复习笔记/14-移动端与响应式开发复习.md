# 移动端与响应式开发复习

> 移动端适配和响应式设计是现代前端必备技能，通过 viewport、rem/vw 单位、媒体查询、弹性布局等技术，确保网页在不同设备上都有良好的显示效果。

## 一、移动端基础

### 1.1 移动端 viewport（视口）

移动端浏览器默认存在三种视口：

| 视口类型 | 说明 | 默认值 |
| --- | --- | --- |
| layout viewport（布局视口） | 浏览器默认的视口，较宽，导致页面被缩放显示 | 约 980px |
| visual viewport（视觉视口） | 用户当前看到的区域，会随缩放变化 | 等于屏幕宽度 |
| ideal viewport（理想视口） | 让布局视口 = 屏幕宽度，是移动端适配的目标 | 屏幕实际宽度 |

通过 `meta viewport` 标签把布局视口设为理想视口：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0, user-scalable=no">
```

| 属性 | 说明 |
| --- | --- |
| `width=device-width` | 视口宽度等于设备宽度（关键） |
| `initial-scale=1.0` | 初始缩放比例 |
| `maximum-scale=1.0` | 最大缩放比例 |
| `minimum-scale=1.0` | 最小缩放比例 |
| `user-scalable=no` | 禁止用户手动缩放 |

> ⚠️ **易错点**：PC 端页面如果不写 viewport，在手机上会以 980px 显示并整体缩小；移动端必须写 viewport 才能正常适配。

### 1.2 物理像素与 CSS 像素

- **物理像素**：设备屏幕实际的像素点（出厂固定，不可改变）
- **CSS 像素**：CSS 中使用的逻辑像素（如 `width: 100px`）
- **设备像素比 DPR** = 物理像素 / CSS 像素

```js
// 获取设备 DPR
console.log(window.devicePixelRatio)  // 例如 iPhone 普通 2，Plus/Pro 3
```

| 设备 | 物理像素 | CSS 像素 | DPR |
| --- | --- | --- | --- |
| iPhone 6/7/8 | 750 × 1334 | 375 × 667 | 2 |
| iPhone 6/7/8 Plus | 1080 × 1920 | 414 × 736 | 3 |
| 普通 Android | 1080 × 1920 | 360 × 640 | 3 |

> ⚠️ **易错点**：在 Retina 屏（DPR=2）上，1px CSS 像素 = 2 个物理像素，所以画 1px 边框会比设计稿偏粗，需特殊处理（见 2.4）。

### 1.3 移动端与 PC 端的区别

| 对比项 | PC 端 | 移动端 |
| --- | --- | --- |
| 交互方式 | 鼠标点击 + 键盘 | 触摸 + 手势 |
| 屏幕尺寸 | 大（≥1024px） | 小（通常 ≤ 768px） |
| 网络环境 | 稳定、高速 | 不稳定、流量敏感 |
| 事件 | click / mouseover | touchstart / touchmove / touchend |
| 兼容性 | 主流浏览器为主 | WebView 内核差异大 |

## 二、移动端适配方案

### 2.1 rem 适配

- `rem` 单位：相对于根元素 `<html>` 的 `font-size`
- `flexible.js` 原理：动态设置 `html` 的 `font-size = 屏幕宽度 / 10`
- 设计稿宽度 750px 时：`1rem = 75px`

```html
<!-- 引入 flexible.js -->
<script src="https://cdn.jsdelivr.net/npm/lib-flexible/flexible.js"></script>
```

```js
// flexible.js 核心原理（简化版）
function setRem() {
  const docEl = document.documentElement
  const width = docEl.clientWidth
  docEl.style.fontSize = width / 10 + 'px'  // 屏幕宽 / 10
}
setRem()
window.addEventListener('resize', setRem)
```

px → rem 换算（设计稿 750px）：

```
设计稿 100px → 100 / 75 ≈ 1.333rem
设计稿  50px →  50 / 75 ≈ 0.667rem
```

> 💡 **重点**：VSCode 安装 `pxcooker` 或 `cssrem` 插件，配置 `root font-size: 75` 即可自动转换。

### 2.2 vw 适配（推荐）

- `vw`：视口宽度的 1%（1vw = 屏幕宽度 / 100）
- `vh`：视口高度的 1%
- `vmin`：vw 和 vh 中较小者
- `vmax`：vw 和 vh 中较大者

px → vw 换算公式：

```
vw = px / (设计稿宽度 / 100)
```

设计稿 750px 时：`100px / (750/100) = 100 / 7.5 ≈ 13.333vw`

```css
/* 设计稿 750px，100px 的盒子 */
.box {
  width: 13.333vw;   /* 100px / 7.5 */
  height: 13.333vw;
  font-size: 4.267vw; /* 32px / 7.5 */
}
```

> 💡 **重点**：VSCode 安装 `px-to-vw` 插件，配置设计稿宽度即可自动转换，无需引入任何 JS。

### 2.3 rem 与 vw 对比

| 对比项 | rem | vw |
| --- | --- | --- |
| 依赖 | 需引入 flexible.js | 浏览器原生支持 |
| 兼容性 | 好（兼容老机型） | 较好（iOS 8+、Android 4.4+） |
| 计算基准 | 相对 html 的 font-size | 相对视口宽度 |
| 精确度 | 受 JS 取整影响 | 浏览器原生计算，更精确 |
| 推荐度 | 中（老项目） | 高（新项目首选） |
| 是否需要 JS | 是 | 否 |

> ⚠️ **易错点**：vw 在极小屏（如 320px）或极大屏上字体可能过小或过大，可配合 `calc()` 设置上下限：

```css
html {
  font-size: calc(14px + 2vw);  /* 最小 14px 起步 */
}
```

### 2.4 1px 边框问题

- **原因**：DPR > 1 时，1px CSS 像素对应多个物理像素，显示偏粗
- **解决方案**：伪元素 + `transform: scale(0.5)`

```css
/* 通用 1px 边框方案 */
.border-1px {
  position: relative;
}
.border-1px::after {
  content: '';
  position: absolute;
  left: 0;
  top: 0;
  width: 200%;
  height: 200%;
  border: 1px solid #ccc;
  border-radius: 10px;       /* 同步圆角 */
  transform: scale(0.5);
  transform-origin: left top;
  box-sizing: border-box;
  pointer-events: none;
}
```

## 三、移动端特殊处理

### 3.1 Box Model 与默认样式

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;          /* 推荐使用 border-box */
  -webkit-tap-highlight-color: transparent;  /* 去除点击高亮 */
}
```

| 属性 | 作用 |
| --- | --- |
| `box-sizing: border-box` | width 包含 padding 和 border，避免溢出 |
| `-webkit-tap-highlight-color: transparent` | 去除 iOS 点击灰色高亮 |
| `-webkit-touch-callout: none` | 禁止长按弹出菜单 |
| `-webkit-user-select: none` | 禁止文本选中 |
| `-webkit-overflow-scrolling: touch` | iOS 平滑滚动 |
| `-webkit-appearance: none` | 移除默认外观（按钮、表单） |

### 3.2 移动端触摸事件

| 事件 | 触发时机 |
| --- | --- |
| `touchstart` | 手指触摸屏幕 |
| `touchmove` | 手指在屏幕上滑动 |
| `touchend` | 手指离开屏幕 |
| `touchcancel` | 系统取消触摸（如电话打断） |

```js
const box = document.querySelector('.box')
box.addEventListener('touchstart', (e) => {
  console.log('触摸点：', e.touches)        // 当前所有触摸点
  console.log('改变触摸点：', e.changedTouches)
  console.log('目标触摸点：', e.targetTouches)
})
```

**touch 事件 vs click 事件（300ms 延迟）**：

- 移动端 click 为区分单击/双击缩放，会有约 300ms 延迟
- 解决方案：① 引入 fastclick 库 ② 用 touchstart 替代 ③ viewport 设置 `user-scalable=no` 后现代浏览器会自动消除延迟

```html
<!-- fastclick 解决方案 -->
<script src="https://cdn.jsdelivr.net/npm/fastclick@1.0.6/lib/fastclick.js"></script>
<script>
  if ('addEventListener' in document) {
    document.addEventListener('DOMContentLoaded', () => {
      FastClick.attach(document.body)
    })
  }
</script>
```

### 3.3 移动端常用 CSS

```css
/* 禁止长按弹出菜单与图片保存 */
img, a {
  -webkit-touch-callout: none;
}

/* 禁止文本选中（按钮、图标区域） */
.no-select {
  -webkit-user-select: none;
  user-select: none;
}

/* iOS 平滑滚动 */
.scroll-box {
  overflow: auto;
  -webkit-overflow-scrolling: touch;
}

/* 禁止文字自动调整大小 */
html {
  -webkit-text-size-adjust: 100%;
}
```

### 3.4 图片适配

```css
/* 响应式图片：不超出容器并保持比例 */
img {
  max-width: 100%;
  height: auto;
  display: block;   /* 去除图片底部默认间隙 */
}
```

**响应式图片 srcset 与 sizes**：

```html
<!-- 根据设备 DPR 和屏幕宽度加载不同图片 -->
<img
  src="small.jpg"
  srcset="small.jpg 480w, medium.jpg 800w, large.jpg 1200w"
  sizes="(max-width: 600px) 480px, (max-width: 900px) 800px, 1200px"
  alt="响应式图片">
```

> ⚠️ **易错点**：`srcset` 中的 `480w` 表示图片实际宽度（不是视口宽度），浏览器根据 `sizes` 自动选择最合适的图。

## 四、响应式设计

### 4.1 响应式 vs 自适应

| 对比项 | 响应式（Responsive） | 自适应（Adaptive） |
| --- | --- | --- |
| 实现方式 | 一套代码 + 媒体查询 + 弹性布局 | 不同设备加载不同页面 |
| 维护成本 | 低（一套代码） | 高（多套代码） |
| 用户体验 | 流畅过渡 | 切换感明显 |
| SEO | 一个 URL 利于收录 | 多 URL 需做对应 |
| 适用场景 | 内容型网站、官网 | 复杂业务（如电商 PC/移动不同站） |

### 4.2 媒体查询 @media

```css
/* 基本语法 */
@media 媒体类型 and (媒体特征) {
  /* 满足条件时生效的样式 */
}
```

| 媒体类型 | 说明 |
| --- | --- |
| `all` | 所有设备（默认，可省略） |
| `screen` | 屏幕（最常用） |
| `print` | 打印机 |
| `speech` | 语音合成器 |

| 媒体特征 | 说明 |
| --- | --- |
| `width` / `min-width` / `max-width` | 视口宽度 |
| `height` / `min-height` / `max-height` | 视口高度 |
| `orientation` | 横屏 `landscape` / 竖屏 `portrait` |
| `resolution` | 分辨率（dpi） |
| `aspect-ratio` | 宽高比 |

| 逻辑操作符 | 说明 |
| --- | --- |
| `and` | 同时满足多个条件 |
| `not` | 取反（注意优先级低，作用于整个媒体查询） |
| `only` | 防止旧浏览器忽略样式（现代浏览器可省略） |
| `,`（逗号） | 或关系 |

**示例（来自项目 01-媒体查询语法.html）**：

```css
/* 当屏幕宽度 >= 1200px，背景绿色 */
@media screen and (min-width: 1200px) {
  body { background-color: green; }
}

/* 当屏幕宽度在 768px ~ 1200px，背景橙色 */
@media screen and (min-width: 768px) and (max-width: 1200px) {
  body { background-color: orange; }
}

/* 当屏幕宽度 < 768px，背景红色 */
@media screen and (max-width: 768px) {
  body { background-color: red; }
}
```

### 4.3 断点设置

| 设备类型 | 宽度范围 | Bootstrap 前缀 |
| --- | --- | --- |
| 超小屏（手机） | < 576px | 默认（无前缀） |
| 小屏（平板竖屏） | 576px ~ 768px | `sm` |
| 中屏（平板横屏） | 768px ~ 992px | `md` |
| 大屏（桌面） | 992px ~ 1200px | `lg` |
| 超大屏（大桌面） | ≥ 1200px | `xl` |

> ⚠️ **易错点**：断点值不要写死，应结合设计稿与 Bootstrap 等框架统一约定。常见也有用 768 / 992 / 1200 的简化版本。

### 4.4 响应式布局策略

| 策略 | 写法 | 说明 |
| --- | --- | --- |
| 移动优先 | `min-width` | 从小到大写，默认样式是移动端，逐步增强 |
| PC 优先 | `max-width` | 从大到小写，默认样式是 PC 端，逐步降级 |

```css
/* 移动优先写法（推荐） */
.box { width: 100%; }                      /* 默认移动端 */
@media (min-width: 768px) {
  .box { width: 50%; }                     /* 平板 */
}
@media (min-width: 992px) {
  .box { width: 33.33%; }                  /* 桌面 */
}
```

### 4.5 响应式工具

**Bootstrap 栅格系统（12 列）**：

```html
<!-- container > row > col 三层结构 -->
<div class="container">
  <div class="row">
    <!-- xl:6列(一行6个) lg:4列 md:4列 sm:6列 -->
    <div class="col-xl-2 col-lg-3 col-md-4 col-sm-6">1</div>
    <div class="col-xl-2 col-lg-3 col-md-4 col-sm-6">2</div>
    <div class="col-xl-2 col-lg-3 col-md-4 col-sm-6">3</div>
    <div class="col-xl-2 col-lg-3 col-md-4 col-sm-6">4</div>
  </div>
</div>
```

| Bootstrap 类 | 说明 |
| --- | --- |
| `.container` | 固定宽度容器，有最大宽度并居中 |
| `.container-fluid` | 流式容器，占满 100% 宽度 |
| `.row` | 行，必须放在 container 内 |
| `.col-*` | 列，一行最多 12 份 |
| `.col-{sm|md|lg|xl}-n` | 响应式列：在指定断点上一行占 n 份 |

**Flexbox 弹性布局**：

```css
.box {
  display: flex;
  flex-wrap: wrap;   /* 允许换行 */
}
.box .item {
  flex: 1;           /* 等分剩余空间 */
  min-width: calc(25% - 16px);  /* 配合媒体查询调整每行个数 */
  max-width: calc(25% - 16px);
  margin: 0 8px 16px;
}
```

## 五、响应式实战技巧

### 5.1 响应式字体

```css
html { font-size: 16px; }
@media (min-width: 768px) { html { font-size: 18px; } }
@media (min-width: 1200px) { html { font-size: 20px; } }

/* 或使用 clamp() 一步到位 */
html {
  font-size: clamp(14px, 2vw, 20px);
}
```

### 5.2 响应式图片

**picture 标签 + source**：

```html
<picture>
  <source media="(max-width: 768px)" srcset="mobile.jpg">
  <source media="(min-width: 1200px)" srcset="desktop.jpg">
  <img src="default.jpg" alt="默认图片">
</picture>
```

**background-image 媒体查询切换**：

```css
.banner {
  background-image: url('mobile.jpg');
}
@media (min-width: 768px) {
  .banner {
    background-image: url('pc.jpg');
  }
}
```

### 5.3 响应式导航

| 设备 | 形式 |
| --- | --- |
| PC 端 | 横向导航栏，菜单全部展开 |
| 移动端 | 汉堡菜单 + 抽屉，点击展开 |

```html
<!-- Bootstrap 响应式导航：lg 以上展开，以下折叠 -->
<nav class="navbar navbar-expand-lg navbar-dark bg-dark fixed-top">
  <div class="container">
    <a class="navbar-brand" href="#">vivo</a>
    <!-- 汉堡按钮：lg 以下显示 -->
    <button class="navbar-toggler" type="button"
            data-bs-toggle="collapse" data-bs-target="#nav">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="nav">
      <ul class="navbar-nav me-auto">
        <li class="nav-item"><a class="nav-link active" href="#">首页</a></li>
        <li class="nav-item"><a class="nav-link" href="#">产品</a></li>
        <li class="nav-item"><a class="nav-link" href="#">关于</a></li>
      </ul>
    </div>
  </div>
</nav>
```

### 5.4 隐藏与显示

```css
/* 媒体查询控制显隐 */
.mobile-only { display: block; }
.pc-only { display: none; }

@media (min-width: 768px) {
  .mobile-only { display: none; }
  .pc-only { display: block; }
}
```

| Bootstrap 工具类 | 说明 |
| --- | --- |
| `.d-none` | 所有设备隐藏 |
| `.d-md-block` | md 及以上显示 |
| `.d-md-none` | 仅 md 以下显示 |
| `.d-block d-md-none` | 仅移动端显示 |
| `.d-none d-md-block` | 仅 PC 端显示 |

### 5.5 仿京东响应式布局（项目实例）

利用 flex + 媒体查询，实现不同屏幕一行显示不同个数：

```css
.box {
  display: flex;
  flex-wrap: wrap;
  width: 80%;
  min-width: 1215px;
  max-width: 1780px;
  margin: 0 auto;
}
.box .item {
  flex: 1;
  height: 120px;
  margin: 0 8px 16px;
}
/* 大屏：一行 6 个 */
@media screen and (min-width: 1536px) {
  .box .item {
    min-width: calc(16.6666667% - 16px);
    max-width: calc(16.6666667% - 16px);
  }
}
/* 中屏：一行 5 个 */
@media screen and (min-width: 1316px) and (max-width: 1536px) {
  .box .item {
    min-width: calc(20% - 16px);
    max-width: calc(20% - 16px);
  }
}
/* 小屏：一行 4 个 */
@media screen and (max-width: 1316px) {
  .box .item {
    min-width: calc(25% - 16px);
    max-width: calc(25% - 16px);
  }
}
```

> ⚠️ **易错点**：用 `flex: 1` 时若不限制 `min-width`/`max-width`，最后一行会被拉满，导致最后一个过大。同时设 `min-width` 和 `max-width` 才能保证每项等宽。

### 5.6 vivo 响应式项目要点

来自 `06-vivo响应式网站` 项目：

- 引入 Bootstrap 5 + Bootstrap Icons
- `navbar-expand-lg` 实现 lg 断点折叠导航
- `col-md-4` 实现中屏以上 3 列卡片布局
- `col-lg-3 col-md-6` 实现 footer 大屏 4 列、中屏 2 列
- 自定义 CSS 用 `@media (max-width: 768px)` 隐藏轮播图标题与指示器

```css
/* vivo 项目中的媒体查询 */
@media (max-width: 768px) {
  .navbar { padding: 5px 0; }
  .carousel-caption,
  .carousel-indicators { display: none; }   /* 移动端隐藏文字 */
}
@media (max-width: 992px) {
  .banner { margin-top: 80px; }             /* 中屏以下让出导航栏空间 */
}
```

## 💡 关联面试题

**Q1：移动端适配有哪些方案？rem 和 vw 的区别？**
- 主流方案：rem 适配（flexible.js）、vw 适配、百分比、响应式布局
- rem：相对 `html` 的 `font-size`，需 JS 动态设置，兼容性好
- vw：相对视口宽度，浏览器原生支持，无需 JS，新项目首选
- 区别：rem 依赖 JS 计算，vw 由浏览器直接渲染；vw 更精确，rem 兼容更老机型

**Q2：物理像素和 CSS 像素的区别？什么是 DPR？**
- 物理像素：设备屏幕实际像素点，出厂固定
- CSS 像素：CSS 中的逻辑像素，如 `width: 100px`
- DPR（设备像素比）= 物理像素 / CSS 像素，可通过 `window.devicePixelRatio` 获取
- Retina 屏 DPR 为 2 或 3，1 个 CSS 像素对应多个物理像素

**Q3：viewport 的作用？ideal viewport 是什么？**
- viewport 通过 `<meta name="viewport">` 控制移动端视口
- 三种视口：layout viewport（默认 980px）、visual viewport、ideal viewport
- ideal viewport：布局视口宽度 = 设备屏幕宽度，是适配目标
- 关键设置：`width=device-width, initial-scale=1.0`

**Q4：媒体查询的语法？常见的断点如何设置？**
- 语法：`@media 媒体类型 and (媒体特征) { 样式 }`
- 类型：screen / print / all；特征：width / orientation / resolution
- 常见断点：手机 <768px、平板 768~992px、桌面 992~1200px、大屏 ≥1200px
- 两种策略：移动优先用 `min-width`，PC 优先用 `max-width`

**Q5：响应式设计和自适应设计有什么区别？**
- 响应式：一套代码 + 媒体查询 + 弹性布局，所有设备共用，流畅过渡
- 自适应：不同设备加载不同页面，针对性强但维护多套代码
- 响应式适合内容站、官网；自适应适合复杂业务（电商 PC/移动分开）

**Q6：移动端 1px 边框问题的原因和解决方案？**
- 原因：DPR>1 时 1 个 CSS 像素对应多个物理像素，1px 边框显示偏粗
- 解决：用伪元素绘制 200% 尺寸的边框，再 `transform: scale(0.5)` 缩放
- 也可用 `border-image`、`box-shadow` 模拟或 viewport 缩放方案

**Q7：移动端 300ms 点击延迟的原因和解决？**
- 原因：移动端为区分单击/双击缩放，click 事件延迟约 300ms
- 解决：① viewport 设置 `user-scalable=no`（现代浏览器自动消除延迟）② 引入 fastclick 库 ③ 用 touchstart 替代 click

**Q8：如何实现响应式图片？**
- `max-width: 100%; height: auto;` 让图片不超出容器
- `srcset` + `sizes`：根据屏幕宽度和 DPR 加载不同尺寸图片
- `<picture>` + `<source media>`：按媒体查询切换图片源
- 背景图用 `@media` 切换 `background-image`
